PRESENCE + OUTSIDE-APP NOTIFICATION DEPLOYMENT
----------------------------------------------------------------

1. Upload this api_app folder over the server's existing api/api_app folder.
   Keep the server's own database credentials and Firebase service-account file secure.

2. Set strong server environment values:

   APP_ASSIGNMENT_PUSH_KEY=<long-random-secret>
   APP_PRESENCE_CRON_KEY=<different-long-random-secret>
   FIREBASE_SERVICE_ACCOUNT_PATH=<absolute-private-path-to-service-account-json>

3. Run stale-presence maintenance every 5 minutes:

   */5 * * * * /usr/bin/php /absolute/path/to/api/api_app/expire-stale-presence.php >/dev/null 2>&1

4. In the dispatcher/admin assignment code, after the assignment transaction commits,
   POST the committed assignment_id to:

   /api/api_app/send-assignment-notification.php

   Header:
   X-Assignment-Key: <APP_ASSIGNMENT_PUSH_KEY>

   Body (form encoded):
   assignment_id=815

5. Dispatcher selection must require BOTH fresh presence and available status:

   p.is_online = 1
   p.last_seen_at >= NOW() - INTERVAL 60 MINUTE
   u.unit_status = 'available'

6. Do not roll back a committed incident assignment only because FCM delivery failed.
   Log the push error; the responder app will load the assignment on its next API refresh.

Full details and a PHP cURL example are in PRESENCE_BACKGROUND_NOTIFICATIONS.md.
